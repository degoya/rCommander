## 0.1.0

The first release: Windows batch files (`.bat`, `.cmd`) coloured like an editor - commands,
labels, variables, strings, numbers, comments, operators and redirections, blocks over lines and
`^` continuations. The setting Encoding reads the file as UTF-8, cp850, cp437 or Windows-1252;
`auto` takes UTF-8 when the file is UTF-8, else cp850.
