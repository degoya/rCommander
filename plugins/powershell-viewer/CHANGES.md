## 0.1.0

The first release: PowerShell scripts, modules and module manifests (`.ps1`, `.psm1`, `.psd1`)
coloured like an editor - keywords, cmdlets and function names, variables, types and attributes,
parameters and operators, strings with the variables and `$( )` in them, here-strings, numbers
and comments, also over several lines. A string the file leaves open shows as invalid. The
setting Encoding reads the file as UTF-8, UTF-16 LE or Windows-1252; `auto` follows a byte-order
mark, else takes UTF-8 when the file is UTF-8, else Windows-1252.
