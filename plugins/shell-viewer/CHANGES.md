# Changes

## 0.2.0

More files: the start files of zsh (`.zshenv`, `.zprofile`, `.zlogin`, `.zlogout`), bash
(`.bash_login`, `.bash_logout`, `.bash_aliases`) and ksh (`.kshrc`), direnv's `.envrc`, and the
package recipes `PKGBUILD` and `APKBUILD` by their name (rCommander 0.19.0 and later).

## 0.1.1

Built against plugin contract 0.3.0; nothing else changed.

## 0.1.0

The first release: sh, bash, zsh and ksh scripts coloured like an editor - found by extension,
as `.bashrc`-style dot files or by their shebang - with the text as the file has it.
