# scripts/

Every build, check, package and repository chore of rCommander is a script here; nothing is
retyped by hand. The heavy ones take the build lock themselves (`scripts/lib/lock.sh`,
`/tmp/rc-build.lock`; `grep -l rc_take_lock scripts/*.sh` names them) - never wrap them in
`flock`. A cargo command that compiles goes through `cargo.sh`, the same lock. The public repository on GitHub leaves out
the maintainer's own workflow scripts that `public-exclude.txt` names (job files, worktrees, the
local CI, measurements, the live servers); their rows below describe the development repository.

| Script | What it does | Lock |

| `check.sh --preflight` | Compiles nothing: `cargo fmt --check`, `bash -n` and Python syntax, shellcheck (and its version against `lib/tool-versions.sh`), the script tests (`scripts/tests/*.sh`, `RC_JOBS` at a time, each test's log in the run's `script-tests/`), gitleaks, `git diff --check`, `archive-jobs.sh --check`, the 500-line rule, `cargo deny --offline check`, the migration pins (`sha384sum -c` of `crates/rc-db/migrations.sha384`, and every `.sql` has a pin), `set-version.sh --check`, `check-sdk-templates.sh` and the `--check` form of every generator in `lib/generators.sh` (`licenses.sh --offline --check`, `mcp-coverage.sh --check`, `keyboard-reference.sh --check`, `settings-reference.sh --check`, `wit-reference.sh --check`, `plugin-manifest-defaults.sh --check`, `icon-font.sh --check`). A missing shellcheck, gitleaks or cargo-deny, or another shellcheck version, is a `skip` here and a failure under `--full`; `~/.local/bin`, where the pinned shellcheck is installed, is put in front of `PATH` when the caller's shell lacks it (`rc_user_tools_path`) | no |

| `cargo.sh <cargo arguments...>` | cargo under the build lock (RC-110-34), for a cargo command typed by hand: the arguments as they are, in the caller's directory, cargo's exit code back (199 without the lock, 198 without the memory, as `lib/lock.sh`). `CARGO_BUILD_JOBS` is `RC_JOBS` (`RC_CLIPPY_JOBS` for a clippy with `--workspace`) and `NEXTEST_TEST_THREADS` is `RC_TEST_THREADS` unless the caller set them. | `nightly.sh` | `check.sh --full` with `NEXTEST_PROFILE=ci` (JUnit, one retry, flaky tests named), the exit as the log's last line `REAL EXIT: <n>`; logs and JUnit in `RC_NIGHTLY_LOGS` (default `~/.local/state/rcommander/nightly`), the newest `RC_NIGHTLY_KEEP` (14) kept; then `fuzz.sh --seconds $RC_NIGHTLY_FUZZ_SECONDS` (300; 0 fuzzes nothing; a machine without the nightly or cargo-fuzz skips it and the log says so, a finding fails the run).
